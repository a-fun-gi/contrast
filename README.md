## About the Game

In contrast, you are navigating a strange liminal space. There is only black and white, as this world has no color and never will. Your only goal is to survive, and to maybe learn why you are here, and how you could get out.

### Controls

Use WASD to move for keyboard. For controller use left stick and bottom button.
